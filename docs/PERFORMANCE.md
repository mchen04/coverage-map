# Performance

Measured on the Mac mini (Apple M4, 24 GB) on both cases, baseline and final interleaved in
the same window on the same data, with correctness held constant. The mini is shared, so every
run records its load average and results are medians. Raw JSON: `evidence/bench/`.

| Stage | Baseline | Final | Correctness held |
|---|---|---|---|
| Segmentation (TotalSegmentator wall) | lidc 377 s, pancreas 189 s (CPU) | 105 s, 60 s (MPS, decomposed conv3d, self-tested; CPU fallback) | per-organ Dice ≥ 0.99999 vs the old labels; production labels regenerated (4 / 16 voxels changed) |
| Segmentation memory | main-process peak RSS 7.6 / 6.9 GB | 5.6 / 4.6 GB RSS, which excludes MPS memory; ≥ 6.7 / ≥ 5.7 GB with the MPS driver allocation (a lower bound) | — |
| Live scoring | POST 36–59 ms, server round trip 60–87 ms | 1.4–1.7 ms, 6–7 ms | live and replay fingerprints identical |
| Replay CLI | — | cold 2.5–2.8x, warm 2x faster | identical coverage |
| Page load | 3D map ready 141–152 ms after the first image | 92 ms; first image 470–485 ms vs stock OHIF 492–499 ms | UI check passes |
| Render (`covmap render`) | 869–951 ms | 529–556 ms | PNG sha256 identical |

Each section lists the harness, then one line per round: change | result | correctness |
load | decision. `round_analysis final` is the interleaved baseline-vs-final run.
